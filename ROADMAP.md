# Roadmap

## Phase 0 — Foundation

- Repository initialized.
- Verification-first operating model documented.
- Claims and assumptions separated.
- Initial architecture and threat model established.
- Quality gates and grant maximization controls established.

## Phase 1 — Evidence & Specification

- Import and classify authoritative project source materials.
- Build complete evidence register.
- Define system requirements and non-goals.
- Create traceability between requirements, components, tests, and KPIs.

## Phase 2 — Core Engineering

- Implement policy/capability control layer.
- Implement authorization and approval boundaries.
- Implement transactional mutation and recovery primitives.
- Establish observability and audit records.

## Phase 3 — NeuroMesh Technical Automation

- Define geometry-processing task classes.
- Establish deterministic baselines.
- Implement AI-assisted operations only where justified.
- Benchmark quality, latency, resource use, and reproducibility.

## Phase 4 — Adversarial Verification

- Threat-driven tests.
- Prompt/tool injection tests.
- Unauthorized capability tests.
- Failure and rollback tests.
- Documentation/implementation consistency tests.

## Phase 5 — Grant Package

- Verify current program rules from official sources.
- Build work packages, milestones, budget, KPIs, risks, and evidence package.
- Run reviewer simulation and rejection red-team.
- Final claim and funding defensibility audit.

## Phase 6 — Release Readiness

A release requires verified evidence, passing quality/security gates, documented residual risks, and synchronized code/documentation/roadmap state.
