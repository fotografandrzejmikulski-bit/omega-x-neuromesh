This is the minimal evidence list required to move the dossier from IN PROGRESS toward READY.

| ID | Evidence required | Why it matters | Status |
|---|---|---|---|
| ER-001 | Current project snapshot: what actually exists today | Prevents concept/implementation conflation | MISSING |
| ER-002 | UE/UEFN technology used or intended and concrete integration point | Establishes Epic relevance | MISSING |
| ER-003 | Current demonstrator, screenshots, video, build, code, or equivalent artifact | Supports proof of function | MISSING |
| ER-004 | Current development time already invested, if claimed | Supports project maturity and feasibility | MISSING |
| ER-005 | Concrete grant-funded work packages | Supports scope and budget | MISSING |
| ER-006 | Realistic time/cost basis for each work package | Supports requested amount | MISSING |
| ER-007 | Applicant identity / legal status / country / contact details required by application | Eligibility and application completion | MISSING |
| ER-008 | Previous/other funding relevant to this project | Disclosure and budget integrity | MISSING |
| ER-009 | Technical claims needing external or direct evidence | Final claim audit | MISSING |
| ER-010 | Supporting links or artifacts permitted by the application | Reviewer verification | MISSING |

## Evidence rule

Do not replace missing evidence with invented values.

Permitted states:

- VERIFIED
- PARTIAL
- UNKNOWN
- NOT APPLICABLE

## Minimum submission principle

Only evidence necessary to substantiate a material application claim should be added. Avoid building unrelated technical infrastructure solely to improve the appearance of the repository.
