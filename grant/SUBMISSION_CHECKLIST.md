# Grant Submission Checklist

## Program verification

- [ ] Current official program page verified.
- [ ] Eligibility verified.
- [ ] Current funding range/maximum verified.
- [ ] Allowable costs verified.
- [ ] Review criteria verified.
- [ ] Current submission window and deadline verified.
- [ ] Required application materials verified.

## Project integrity

- [ ] Scope matches technical architecture.
- [ ] Deliverables match work packages.
- [ ] Milestones are measurable.
- [ ] KPIs have defined measurement methods.
- [ ] Targets are not presented as results.
- [ ] Material claims have evidence.
- [ ] Open assumptions are disclosed where material.

## Budget integrity

- [ ] Every material cost maps to task, deliverable, KPI, and impact.
- [ ] Full-scope budget is defensible.
- [ ] Reduced/MVP scenarios have been assessed where useful.
- [ ] No unsupported headcount or cost assumptions.
- [ ] Requested amount does not exceed the current program ceiling.

## Red-team

- [ ] Reviewer can identify the problem in one pass.
- [ ] Reviewer can understand the proposed solution without hype.
- [ ] Technical differentiation is evidence-backed.
- [ ] Main risks and mitigations are explicit.
- [ ] Security and responsible-use boundaries are clear.
- [ ] No statement relies on detector evasion, fabricated authorship, or fabricated evidence.

## Final gate

`TRUTH → EVIDENCE → PROJECT → BUDGET → KPIs → RISK → PROGRAM RULES → REVIEWER TEST → SUBMISSION`
