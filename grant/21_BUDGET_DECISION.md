# Budget Decision — MegaGrants Cycle 2

**Date:** 2026-09-04  
**Status:** Provisional budget envelope — final submission amount pending final eligibility/form and necessary non-labor cost verification.

## Decision

Use a **€30/hour** internal planning rate for the solo developer and a **6-month** full-time planning envelope.

`960 hours × €30/hour = €28,800`

Therefore the current FULL scenario is **€28,800**, before any verified necessary non-labor costs.

## Scenarios

| Scenario | Planned hours | Labor envelope | Intended outcome |
|---|---:|---:|---|
| MVP | 480 | €14,400 | Minimal technically credible hypothesis and demonstrator |
| REDUCED | 720 | €21,600 | Narrow demonstrator plus essential validation |
| FULL | 960 | €28,800 | Complete WP1–WP4 development, validation, benchmarking and evidence package |

## Recommendation

**Preferred planning scenario: FULL — €28,800 labor envelope.**

Reason: the project currently lacks an Unreal Engine build environment, so the funded program must cover the transition from source-implemented vertical slice to runtime verification, validation, benchmarking and demonstrator evidence. Reducing the scope too aggressively would weaken the central proof requirement.

## Non-labor costs

Do not invent hardware, software, cloud, compute, rental or dissemination costs. Add them only when a concrete requirement and current price/quote are available and the applicable program rules permit the expense.

The applicant currently has no Unreal Engine build environment. A development machine or equivalent environment may therefore become a necessary project cost, but it remains **unpriced and unconfirmed** and is excluded from the €28,800 envelope until verified.

## Final calculation rule

Before submission:

1. verify all applicant eligibility/form fields;
2. verify required development environment and any necessary non-labor costs;
3. verify current MegaGrants rules and allowable cost treatment;
4. calculate the complete defensible project cost;
5. select the smallest request that fully supports the committed scope;
6. run the final claim audit and reviewer red-team against the actual application text.

No grant request should be inflated to match a program ceiling.
